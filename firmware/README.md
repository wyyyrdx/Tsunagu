# Tsungu Firmware

## Current Stage
- Simulation on Tinkercad (Arduino)
- Reading 5 Flex Sensors
- Basic letter recognition (A, B, C) using thresholds

## File Structure
- `src/main.ino` → Main code for sensor reading and simple gesture recognition

## How to Run (Simulation)
1. Open the code in Tinkercad
2. Connect 5 Flex Sensors to A0 - A4
3. Start simulation and open Serial Monitor
